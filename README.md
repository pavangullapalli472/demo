# demo

This project uses the [ponytail](https://github.com/DietrichGebert/ponytail) Claude Code plugin ("lazy senior dev mode": YAGNI, stdlib first, the shortest code that works).

It's configured in `.claude/settings.json`. When you open this repo in Claude Code and trust the folder, you'll be prompted to install the `ponytail` marketplace and plugin. To install it by hand:

```
/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
```
